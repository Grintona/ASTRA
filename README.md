# ASTRA

Учебный сайт вымышленного космического агентства.

## Student 3 — Technology и About

- [technology.html](technology.html): четыре технологии, иллюстрации и характеристики.
- [about.html](about.html): история, миссия, команда и источники.
- [css/style.css](css/style.css): общие стили всех страниц.
- `images/*.svg`: векторные иллюстрации, подключённые обычным `<img>` с описанием `alt`.

Страницы Student 3 используют HTML, CSS и Bootstrap 5.3.8 через CDN. JavaScript и сборка для них не нужны; для загрузки Bootstrap нужен интернет.

## Что из презентаций используется

| Материал | Пример в коде |
| --- | --- |
| HTML | `header`, `nav`, `main`, `section`, `article`, `footer`; заголовки `h1 → h2 → h3`, списки, ссылки и изображения с `alt`. |
| Week 2 | Внешний CSS после Bootstrap, классы, HEX-цвета, Arial, `padding`, `margin`, `border`, состояния наведения и клавиатурного фокуса. |
| CSS Layouts | Flexbox в меню, Grid для технологий и команды, `gap` между карточками. |
| Bootstrap and Media Queries | `card astra-card` — карточка Bootstrap с нашими цветами и отступами; `row` и `col-12 col-md-6` — миссия и видение на About. |
| Web Design Basics | Один шрифт, общие цвета и меню, заметный главный заголовок, текст слева, свободное пространство между разделами. |

В `.technology-grid` сначала задана одна колонка для телефона. При `min-width: 768px` становятся две: `repeat(2, minmax(0, 1fr))`. `1fr` делит доступное место поровну, а минимум `0` позволяет колонкам сжиматься. В Bootstrap `col-12` занимает всю строку, а `col-md-6` — половину строки от 768 px.

`aria-current="page"` отмечает текущую страницу в меню. `:focus-visible` показывает рамку при навигации клавишей Tab. Иллюстрации — SVG-файлы с линиями и фигурами; их размеры на странице задаёт `.technology-diagram`.

## Проверка перед защитой

Открыть `technology.html` и `about.html` в браузере или запустить из корня проекта `python3 -m http.server 8000` и перейти на `http://localhost:8000/technology.html`.

- В DevTools проверить 375, 768 и 1280 px: нет горизонтальной прокрутки, текст и рисунки не обрезаются.
- Проверить все ссылки меню, кнопку перехода к технологиям и навигацию клавишей Tab.
- Заменить Student 1–3 в About на настоящие имена.
- Для тренировки изменить текст карточки, её `padding` или число колонок и объяснить результат.

В общей сборке пока отсутствуют `images/Logo.jpg`, `images/moon.jpg`, `images/mars.jpg`, `images/europa.jpg` и `js/booking.js`, на которые ссылаются страницы других участников. Также нужно согласовать цены между Home/Destinations и Missions/Booking и длительность поездки на Европу. Это отдельные незавершённые части проекта, а не возможности страниц Student 3.
